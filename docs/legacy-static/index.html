先把话说清楚

ResetRadar 能知道我的准确额度恢复时间吗？

不能。个人额度与恢复时间由各个平台按账户和套餐决定。你填写或授权设备本地读取的时间才是倒计时依据；请始终以平台账户页面为准。

会读取我的 Codex、Claude 或 Grok 账号吗？

不会。这个 MVP 不要求账号、Cookie 或 API 密钥。后续如加入浏览器本地助手，也应默认只在设备侧处理并明确征得同意。

付款后我买到的是什么？

你购买的是通知服务与经核验的信息整理，不是平台额度、额度恢复、API credit，也不保证任何平台的可用性。
